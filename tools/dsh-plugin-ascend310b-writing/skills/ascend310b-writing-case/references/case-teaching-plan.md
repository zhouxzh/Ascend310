## 正文完成前自检

- [ ] 开篇先提出学生能理解的问题，而不是版本矩阵。
- [ ] 学习目标使用可观察动词并绑定产出。
- [ ] 每个核心概念都有解释、例子和检查题。
- [ ] 学生先跑通最小闭环，再进入完整发布门。
- [ ] 每个命令都有工作目录、预期输出和失败分支。
- [ ] 有至少两个形成性检查点和一个独立迁移任务。
- [ ] 正文没有被完整验收报告、历史日志或未验收设计占据。
- [ ] 源码来自固定 GitHub commit，模型来自固定 Hugging Face revision。
- [ ] 板端证据等级和限制写清楚。
