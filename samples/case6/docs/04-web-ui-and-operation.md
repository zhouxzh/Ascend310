# Web 页面与运行操作

## 启动

```bash
cd samples/case6
python3 app.py
```

默认地址：

```text
http://127.0.0.1:7860
```

参数：

```bash
python3 app.py --port 8080
python3 app.py --share
```

`app.py` 固定使用 `server_name="0.0.0.0"`。`--share` 会创建公网访问链接，当前页面没有认证和访问控制。只应在受控实验环境使用；不要把公开链接当成生产部署。

## 页面结构

### 道路感知

- 上传道路图像或使用摄像头输入；
- 点击“开始感知”或上传变化时自动触发；
- 左侧输出车道线叠加图；
- 右侧显示左右车道、Hough 线段数、Top-1、Top-3、建议、总耗时和后端。

### 系统信息

显示：

- 当前后端（NPU 或 CPU）；
- ResNet18/224×224/5 类；
- OM 和 PTH 是否存在；
- Canny、Hough、最小线段和 ROI 顶部参数。

## 停止

前台运行时使用 `Ctrl+C`。Gradio 进程退出后端口应释放；如果使用 `--share`，同时确认公网隧道已关闭。

## 资源与安全

- 输入图像只用于当前请求，不应被写成永久资产；
- 摄像头输入需要设备权限；
- 页面没有登录，`0.0.0.0` 与 `--share` 都扩大访问面；
- 当前代码不实现鉴权、速率限制和审计日志。
