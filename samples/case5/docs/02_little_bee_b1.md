# 02 Little Bee B1：开源电流与磁场探头

本文件说明 Little Bee B1 的接线、声明换算与安全/标定边界。它不是 Hantek 或仪表盘的启动手册；完整实验顺序见 [README](../README.md)。

## 当前状态

Little Bee B1 计划作为 Hantek CH2 的电流或磁场趋势输入。项目已核对公开资料和软件中的声明参数，但尚未记录这只实际探头的 CH2 接入、零点漂移、增益、相位、同步或饱和标定。因此现阶段不能由它得出计量级电流、功率因数、相位角、无功功率或谐波结论。

项目主页：[Little Bee B1](https://github.com/westonb/little-bee-B1)。本项目使用的是淘宝成品，约 450 元是用户提供的参考成交价，不是官方价格，也不代表每个成品的元件、附件或校准一致。

## 原理与连接关系

Little Bee 使用各向异性磁阻（AMR）传感器测量磁场。装上开口铁氧体磁环附件后，一根载流导线的磁场经传感器、可选增益/带宽放大器后，以 SMA 模拟电压形式输出：

```text
单根绝缘导线 -> 开口磁环 -> 与电流相关的磁场 -> AMR 传感器
             -> 增益/带宽 -> SMA 输出 -> SMA-BNC 线 -> 6022BE CH2（1 Mohm）
```

只有需要测量的**一根**导线应穿过磁环。去线和回线同时穿过会产生方向相反的磁场并大幅抵消。没有磁环时，它也可作为磁场探头，但容易受位置、铁磁物体和环境磁场影响，不适合作为首轮定量电流实验。

## 接入与去零

开始前必须满足：被测回路是隔离低压实验回路；导线绝缘完好；Hantek CH2 以 1 Mohm、DC 耦合输入；已停止所有占用 6022BE 的外部程序。

1. 装入一节 AA 电池，安装磁环附件，并让单根绝缘导线穿过磁环。
2. 用 SMA-BNC 线把探头输出接到 Hantek CH2；不要接 50 ohm 端接。
3. 先选黄色低增益模式，避免未知电流使输出饱和；确认峰值后才考虑青色高增益模式。
4. 开机后等待约 3.5 s 自动去零；把探头和导线固定到最终位置，长按 `Reset/Zero` 超过 1 s 再次去零。
5. 每次改变增益、带宽、导线位置或匝数后重新去零，并在会话外记录这些条件。

## 声明换算与必须完成的标定

若探头已去零，输出电压为 `Vout`，所选模式灵敏度为 `S`，导线绕过磁环的匝数为 `N`，则趋势性换算为：

```text
I = Vout / (S * N)
```

例如黄色模式 `S = 0.25 V/A`、单匝、`Vout = 0.5 V` 时，声明换算为 `2 A`。多匝可提高响应，但软件/会话必须记录并除以 `N`，且导线位置应固定，避免几何引入增益变化。

将 CH1 电压与 CH2 电流用于同步时频分析前，至少完成以下本机标定：

1. **示波器通道偏移：** 用同一个隔离低压信号同时送入 CH1/CH2，测量固有时间偏移。
2. **零点：** 在最终安装位置、无电流条件下按探头流程去零；当前仪表盘不保存 `Vzero`，也不做软件零点扣除。
3. **增益：** 用已知电阻负载和参考表在多个电流点拟合实际 V/A。
4. **相位：** 在目标频率范围测量探头、连接线和 CH2 组合延迟。
5. **饱和与电池：** 保存削顶、红灯复位和低电量条件；异常窗口不应进入训练或功率分析。

## 安全边界

Little Bee 的公开操作说明指出它没有 CAT 测量等级，设计用于实验室环境。本项目据此限制为：

- 第一阶段仅测隔离的 12--24 VAC 或低压直流实验回路。
- 不夹市电裸线，不拆开市电设备后测内部导线。
- 不把磁耦合或 AA 电池供电误解为任意共模隔离。
- 电流未知时从低增益开始；红灯或波形失真时，立即断开被测回路并复位探头。
