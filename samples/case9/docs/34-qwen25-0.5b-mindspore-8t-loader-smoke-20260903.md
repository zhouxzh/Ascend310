## 4. 🧪 烟测结果

批次：`qwen25-ms-8t-20260903T114000Z` 的首次 loader 观测没有自动落盘；其原始旁证
仍标为 `evidence_path=not-recorded`。随后在同一板、同一工件和同一环境完成了独立的
NPU 活动采样批次 `qwen25-npu-evidence-20260903T115754Z`，原始文件已从板端按显式
allowlist 同步到本地忽略目录：

```text
repro/mindspore-chat-20260903/reports/board8t/
  qwen2.5-0.5b-mindspore/qwen25-npu-evidence-20260903T115754Z/
```

该目录含 `environment.txt`、`worker.log`、`npu-samples.log`、前后快照、摘要和
`SHA256SUMS.txt`。路径和哈希是复现旁证，不会把 ignored 文件误当成已提交源码。

| 步骤 | 结果 | 耗时/输出 | 判定 |
| --- | --- | --- | --- |
| tokenizer/config 读取 | 成功 | 使用本地 Qwen2.5 缓存 | 诊断通过 |
| MindSpore context | 成功 | `device_target=Ascend` | 环境证据 |
| 模型加载 | 成功 | `50.293 s` | 仅说明 loader 返回模型 |
| 严格 placement 检查（默认） | 失败 | 无可枚举的显式 Ascend 参数 placement | **阻断** |
| 放宽 placement 的诊断生成 | 完成 | 首次观测 `12.009 s`；独立采样批次 `27.194196 s` / 16 token；文本：`我是来自阿里云的超大规模语言模型，我叫通义千问` | context-only，不可准入 |
| 输出 placement | 未获得参数级证据 | provider 状态为 `context_only` | **阻断** |

独立采样批次的 worker 正常退出（return code `0`）。并发 `npu-smi -t usages` 采样到
AICore 非零 10 次、峰值约 `37%`；设备内存使用率约从 `38%` 升到 `91%`，采样结束
回落到约 `46%`，进程退出后回到约 `38%`。这构成“运行期间确有 NPU 活动/设备内存
分配”的硬件旁证，但仍不是模型参数 placement metadata，也不能解除严格门。

原始摘要中还记录了 `DRV_LPM_FAULT 0x80E3A203`、`event_sched -512` 和资源清理警告；
这些是需要后续调查的板端稳定性风险，不能被一次成功退出覆盖。

严格检查失败的含义是：当前 MindNLP 模型对象没有暴露可审计的参数级 Ascend placement
元数据。它不等价于“确定运行在 CPU”，也不允许我们反过来宣称“确定运行在 NPU”。在
证据补齐前，服务必须保持 fail-closed。

## 5. 🚧 门禁状态

| 门 | 当前状态 | 原因 |
| --- | --- | --- |
| G0 环境 | `environment_verified`（诊断批次） | 8T/CANN/ACL/MindSpore 可导入；dirty-base 需保留标签 |
| G1 工件 | `artifact_verified`（最小集） | 权重、tokenizer、config 大小/SHA-256 已核对；旁证目录另有逐文件 SHA-256 |
| G2 加载/单 token NPU | `blocked` | 已有 AICore/设备内存活动旁证，但严格 placement metadata 缺失，且存在 LPM/resource-cleanup 诊断 |
| G3 JSON/SSE API | `not-run` | 未启动 8090 服务 |
| G4 长输出 | `not-run` | 未执行 8/16/32/64 token |
| G5 稳定性 | `not-run` | 未执行 10 轮 |
| G6 中文/英文质量 | `not-run` | 单句诊断输出不能构成质量集 |
| G7 性能 | `not-run` | 单次加载/生成不能构成性能样本 |
| G8 候选链/UI | `not-run` | 未触碰 7867/7868 |

因此注册表把 `Ascend310B4` 行更新为 `blocked`，理由为
`strict placement evidence unavailable; context-only diagnostic smoke is not admission evidence`。
Profile 总状态也保持 `blocked`/不可切换；20T 行保持 `not-run`，不能用本板结果推断。
