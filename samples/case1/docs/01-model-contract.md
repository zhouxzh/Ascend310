# Case 1 模型合同

本文档描述 Case 1 的模型文件角色、输入输出约定和验证边界。文件名和形状是
工程合同，不是对网络论文名称、训练数据或识别精度的替代说明。模型二进制和
转换日志保留在开发板或受控的资产目录，不提交到 Git。

## 模型清单

| 角色 | 准备阶段文件 | 运行阶段文件 | 调用方 |
| --- | --- | --- | --- |
| 检测 | `models/det_500m.onnx` | `models/face_detection.om` | `FaceSystem.detect` |
| 特征提取 | `models/w600k_mbf.onnx` | `models/face_recognition.om` | `FaceSystem.get_embedding` |

`prepare_models.py` 可以下载或定位 ONNX 并构造 ATC 命令。若目录中使用了不同
文件名，应通过命令行参数或配置显式指定，不要仅修改文档中的名称。

## 输入合同

| 模型 | 形状 | 类型 | 当前前处理 |
| --- | --- | --- | --- |
| 检测 | `1×3×640×640` | 浮点数组 | BGR 图像缩放、归一化、`NCHW` 转置 |
| 特征提取 | `1×3×112×112` | 浮点数组 | 人脸裁剪缩放、归一化、`NCHW` 转置 |

形状和归一化常数来自当前运行代码的假设。真正部署前必须读取 ONNX 图或 OM
描述，确认数据类型、布局、均值和尺度；若任一项不一致，应先修正前处理或
转换参数，再执行推理。摄像头原始分辨率不属于模型输入形状，缩放操作必须
在进入模型前完成。

## 输出合同

### 检测输出

当前后处理实现按三种 stride（8、16、32）组织分数和边界框距离，并预留关键点
输出。因此代码期望检测模型提供九个可解释的输出张量：三组分数、三组边界框
偏移和三组关键点。这个顺序必须由 `scripts/check_onnx_out.py` 和板端样本
推理确认；“能够加载 OM”不能证明输出顺序正确。

后处理步骤为：

1. 将各尺度输出展平并拼接；
2. 用分数阈值筛选候选；
3. 按锚点和 stride 解码边界框，并缩放回原始图像坐标；
4. 使用 NMS 去除重叠框；
5. 对越界坐标做裁剪，丢弃面积为零的结果。

若模型实际输出使用中心偏移、不同锚点数量或不同排列，必须替换解码逻辑并
重新记录合同。当前距离解码只是实现假设，不是对模型论文结构的命名或证明。

### 特征输出

当前代码从第一个输出缓冲区读取 `float32` 数组，并将其作为用户特征保存。样例
预期向量长度为 512，但最终维度应以 ONNX/OM 描述和板端输出字节数为准。存入
SQLite 前应检查数组连续性、数据类型和长度；读取 BLOB 时使用同样的类型和
字节序，模型更换后不得直接混用旧特征。

## 比对合同

对查询向量 $q$ 与用户向量 $v$ 计算：

$$
s(q,v)=\frac{q\cdot v}{\lVert q\rVert_2\lVert v\rVert_2+\epsilon}.
$$

服务选择最高相似度并与配置阈值比较。阈值是演示参数，不是已校准的安全边界；
任何精度、召回率或误识别结论都必须绑定数据集、用户协议、阈值、模型摘要和
原始报告。空向量、长度不一致或 NaN 应导致请求失败，而不是被当作低相似度。

## 检查工具和执行边界

开发机可以运行静态 ONNX 检查：

```bash
cd samples/case1
python scripts/check_onnx.py models/det_500m.onnx models/w600k_mbf.onnx
python scripts/check_onnx_out.py models/det_500m.onnx models/w600k_mbf.onnx
```

ATC、PyACL、OM 加载和 NPU 数值检查只能在具有匹配 CANN 的昇腾设备上执行。每
次转换应保留：

- SoC 类型和 CANN 版本；
- 完整 ATC 参数和退出状态；
- 输入输出检查结果；
- 生成 OM 的文件大小、摘要和保存位置；
- ACL 首次推理的输出形状与错误日志。

这些记录分别证明资产完整性、转换成功和运行成功，不能相互替代。

## 失败语义

服务启动时若模型不存在、加载失败或合同检查未通过，健康状态为 `degraded`。
依赖模型的注册、打卡和摄像头自动考勤接口返回 HTTP `503`，并说明模型尚未
就绪。禁止使用随机向量、零向量或 CPU 模型作为静默回退；测试可以通过显式
fake runtime 注入替代硬件，但替代结果必须标为模拟结果。
