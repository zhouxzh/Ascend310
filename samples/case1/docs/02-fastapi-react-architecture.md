# Case 1 FastAPI 与 React 架构

本文件说明 Web 服务与硬件运行时之间的边界。它不替代 API schema 或板端验收
报告；当代码和本文档不一致时，应先修正合同，再更新说明。

## 组件关系

```text
React/Vite 浏览器
    │ HTTP、multipart、MJPEG
    ▼
FastAPI 应用工厂
    │ lifespan 初始化与关闭
    ▼
单一硬件工作队列       进程内 SQLite 锁
    │
    ├── OpenCV 摄像头与 JPEG 缓存
    └── PyACL context/stream
          ├── face_detection.om
          └── face_recognition.om
```

FastAPI 层不重复实现推理算法。它负责请求解析、大小和路径约束、任务提交、
响应编码和静态资源托管；运行层负责摄像头和模型的有序访问，数据库模块用
进程内可重入锁和 SQLite busy timeout 串行化读写。

## 生命周期

应用工厂在 lifespan 的启动阶段初始化数据库，创建运行时管理器并检查模型合同。
摄像头可以在启动时打开，也可以在首次使用时延迟打开；两种策略都必须在健康
接口中反映真实状态。关闭阶段依次停止新任务、停止流生成器、调用摄像头
`stop()` 并等待线程退出；若线程在期限内未退出，运行时保留 owner 引用并报告
失败，禁止创建第二个硬件 owner。正常关闭时最后释放 OM、Device buffer、stream、
context 和 ACL。不能依赖全局对象析构顺序。

当模型或摄像头不可用时，服务仍可返回静态页面和健康诊断，但所有需要硬件的
接口必须明确返回 `503`。这使“网页可打开”和“推理已就绪”成为两个可独立
观察的状态。

## 请求和任务

注册与手动打卡请求均经过以下边界：

1. 请求字段和文件参数校验；
2. 文件大小、MIME 和 OpenCV 解码检查；
3. 服务端生成资源 ID，禁止客户端决定保存路径；
4. 将图像任务提交给硬件工作队列；
5. 由统一的识别服务执行检测、裁剪、特征和比对；
6. 在数据库锁保护的事务边界内写入 SQLite，并返回最小必要字段。

摄像头自动考勤使用同一识别服务，不从 HTTP 路由复制一套逻辑。摄像头线程
只负责采集和维护最近帧，MJPEG 客户端只读取缓存 JPEG；连接数增加不会增加
NPU 推理次数。摄像头线程和 HTTP 任务共享数据库锁，因此有帧时的自动考勤
不会与用户管理产生 SQLite 写入竞争。

## API 兼容性

迁移到 FastAPI 不改变既有教学 URL：

| 资源 | 方法 | 兼容约定 |
| --- | --- | --- |
| `/api/users` | `GET`/`POST` | 列表不返回特征；注册接受姓名和图像 |
| `/api/users/{id}` | `PUT`/`DELETE` | 名称更新；删除用户及其事件 |
| `/api/camera/capture` | `POST` | 返回服务端资源标识 |
| `/api/clockin` | `POST` | 返回 `match` 和可解释的失败状态 |
| `/api/attendance` | `GET` | 当天每位用户最近一次记录 |
| `/video_feed` | `GET` | `multipart/x-mixed-replace` |

新增 `/api/health` 用于区分 `ok`、`degraded`、模型未就绪和摄像头不可用等状态。模型
缺失、ACL 初始化失败或输出合同错误时，推理接口返回 `503`，而不是 `200` 加
空结果。

## React 交互边界

React 页面应把网络状态、硬件状态和业务匹配状态分开呈现：

- 网络失败显示请求错误；
- `degraded` 显示模型未就绪；
- `match=false` 表示请求成功但没有通过相似度阈值；
- 自动登记显示“教学演示”提示，不显示为已认证身份。

浏览器摄像头使用 `getUserMedia` 时，组件卸载、重新抓拍和请求失败都要停止
媒体轨道。上传预览使用对象 URL 时，完成后调用 `URL.revokeObjectURL`。
页面不将姓名、路径或数据库字段拼接进 `innerHTML`，也不依赖外部 CDN。

## 并发与部署约束

PyACL、OpenCV 和 SQLite 调用是阻塞操作。硬件任务通过单一队列串行化，数据库
调用由进程内锁和 SQLite 超时共同约束。默认启动一个 Uvicorn worker，不启用 reload；
多个 worker 会复制模型、ACL context 和摄像头句柄。默认监听 `127.0.0.1`，
局域网访问须由操作者显式指定地址并限制在可信实验网络。

FastAPI 的自动 OpenAPI 文档、异常堆栈和调试工具不应默认暴露到不可信网络。
正式系统还需要认证、授权、速率限制、审计和加密存储；这些不属于本案例的
已验证结论。
