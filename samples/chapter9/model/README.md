# Chapter 9 Model Directory

The quantized chapter uses the ResNet18-TinyImageNet source model from Hugging Face repository `zhouxzh/resnet18_tiny_imagenet`. Enter `samples/chapter9` and download the source artifact with:

```bash
python tools/download_model.py
```

The downloader is pinned to revision:

```text
dfcf5885dcf7beab3a5d6e2143c73d7973bead36
```

The verified source ONNX contract is:

| Item | Value |
| --- | --- |
| File | `resnet18_tiny_imagenet.onnx` |
| Size | 45,223,270 bytes |
| SHA-256 | `e461aecee8bfafe95cd4528d3e836783c7546a0bb201c98e25109cde51b3bd6e` |

The FP32, FP16 and INT8 OM files are generated locally from this source and its AMCT deploy model. They are not downloaded as prebuilt artifacts. The `resnet18_tiny_imagenet_int8_deploy.onnx` file is the intermediate generated by AMCT before INT8 ATC conversion.
