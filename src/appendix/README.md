# 附录

本部分汇集不属于理论主线或独立项目案例，但对课程学习、实验复现和工程查阅具有长期价值的补充材料。附录按阿拉伯数字顺序组织；当前已收录 `appendix1.md` 至 `appendix6.md`，后续内容依次使用 `appendix7.md`、`appendix8.md` 等文件名扩展。

## 附录列表

### 附录 1：开发板与基础环境

[阅读附录](./appendix1.md)

介绍开发板硬件、配件准备、操作系统安装、启动方式、网络连接、远程访问和基础环境验证，为后续理论学习与项目实践提供统一的实验基础。

### 附录 2：基于昇腾 310B 的 Ubuntu 教程

[阅读附录](./appendix2.md)

从昇腾 310B 板端和开发机的实际操作出发，介绍 Ubuntu 文件系统、用户权限、常用命令、nano/vim、软件包、网络、静态 IP、SSH、VNC、NFS、Docker、热点与 WiFi、程序自启动，以及 CANN、PyACL、ATC/OM、设备、服务和证据边界。

### 附录 3：Python 编程基础

[阅读附录](./appendix3.md)

公选课补充材料，从具体数据问题出发介绍 Python 标准库读取 CSV、变量、容器、条件、循环、函数、异常和调试。

### 附录 4：Vibe Coding 基础

### 附录 5：ROS2 基础教程

### 附录 6：工具箱、FAQ 与参数模板
