\chapter{案例4：智能掌纹识别机}\label{ux6848ux4f8b4ux667aux80fdux638cux7eb9ux8bc6ux522bux673a}

\section{1. 项目简介}\label{ux9879ux76eeux7b80ux4ecb}

本项目基于昇腾 310B 平台，构建一个高精度的掌纹识别系统。掌纹识别作为一种
生物识别技术，具有纹理丰富、难以伪造、非接触式采集等优势，在门禁控制、
考勤管理、身份验证等领域有着广阔的应用前景。

相比传统的指纹识别，掌纹包含更多的特征信息------主线、皱纹、脊线纹理等，能够
提供更高的识别精度和更强的防伪能力。

本案例的\textbf{核心创新}在于将掌纹识别建模为\textbf{开集验证 (open-set
verification)} 问题而非闭集分类问题：系统通过 GhostNet
提取掌纹的深度特征向量，使用 FAISS
进行高效的余弦相似度检索，新用户注册时无需重新训练模型，只需将其特征向量
加入索引即可。

\subsection{2.3.
掌纹图像预处理}\label{ux638cux7eb9ux56feux50cfux9884ux5904ux7406}

掌纹 ROI（感兴趣区域）检测是整个系统的第一道关口。高质量的 ROI
提取直接影响 后续特征提取的准确性。

\subsubsection{预处理流水线}\label{ux9884ux5904ux7406ux6d41ux6c34ux7ebf}

\begin{lstlisting}
flowchart TD
    RAW["摄像头帧\nBGR (H, W, 3)"] --> GRAY["灰度化\ncv2.COLOR_BGR2GRAY"]
    GRAY --> SEG["手掌分割\nGaussianBlur → Otsu 二值化\n形态学闭/开操作"]
    SEG --> CONTOUR["轮廓检测\ncv2.findContours\n取最大轮廓 = 手掌"]
    CONTOUR --> VALLEY["指谷点定位\n凸包缺陷分析\n筛选深度 >3000 的凹陷"]
    VALLEY --> ROI["ROI 提取\n以指谷连线中点为基准\n向下偏移 30% 距离\n提取正方形区域"]
    ROI --> CLAHE["对比度增强\nBGR → LAB\nCLAHE 应用于 L 通道\nLAB → BGR"]
    CLAHE --> CHECK["质量检查\nLaplacian 方差\n< 100 → 重新采集"]
    CHECK --> OUTPUT["输出\n(224, 224, 3) BGR"]
\end{lstlisting}

\subsubsection{关键技术细节}\label{ux5173ux952eux6280ux672fux7ec6ux8282}

\textbf{手掌分割}：使用 Otsu
自适应阈值将手掌与背景分离。系统假设手掌比背景亮 （配合深色背景和 LED
照明）。如果二值化后白色像素超过 50\%，则自动反转
（适应浅色背景场景）。随后通过形态学闭操作填充手掌内部孔洞，开操作去除
孤立噪点。

\textbf{指谷点定位}：计算手掌轮廓的凸包，通过凸性缺陷 (convexity
defects) 定位 手指之间的凹陷点（指谷）。只保留深度超过 3000
像素单位的缺陷点------这有效过滤 掉手腕处的微小凹陷。缺陷点按 x
坐标从左到右排序，取最左和最右两个作为 ROI 坐标系基准。

\textbf{ROI
提取}：以左右两个指谷点的连线中点为参考点，向下偏移连线距离的 30\% 作为
ROI 中心（从指谷移动到掌纹中心区域），ROI 边长为指谷距离的 1.2 倍。
这种几何方法在受控环境下稳定且高效，避免了复杂的机器学习定位。

\textbf{CLAHE 增强}：将 ROI 图像从 BGR 转换到 LAB 色彩空间，仅在亮度 L
通道上应用 CLAHE（对比度受限的自适应直方图均衡化），然后转换回
BGR。这样做在不引入 色彩伪影的前提下显著增强了掌纹纹理的对比度。

全部代码实现在
\href{samples/case4/palm_preprocessor.py}{palm\_preprocessor.py} 的
\passthrough{\lstinline!PalmPreprocessor!} 类中，纯 OpenCV
实现，无需任何模型文件。

\subsubsection{预处理失败的处理}\label{ux9884ux5904ux7406ux5931ux8d25ux7684ux5904ux7406}

预处理可能因以下原因失败：手掌未在画面中、光照过暗/过亮、手指未张开无法
定位指谷点、图像模糊等。\passthrough{\lstinline!PalmPreprocessor.preprocess()!}
在失败时返回 \passthrough{\lstinline!None!}
而非抛出异常，调用方可以优雅地提示用户重新采集。

\subsubsection{Ghost 模块原理}\label{ghost-ux6a21ux5757ux539fux7406}

标准卷积同时生成所有输出通道，存在大量冗余。Ghost 模块将卷积拆分为两步：

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{主卷积 (Primary)}：生成少量''内在''特征图 (输出通道的
  1/ratio，ratio=2)
\item
  \textbf{廉价卷积
  (Cheap)}：对每个内在特征图应用深度可分离卷积，生成''幻影''
  特征图，填充剩余通道
\item
  将两部分拼接，得到完整输出
\end{enumerate}

\begin{lstlisting}[language=Python]
# GhostModule 核心实现 (ghostnet.py)
class GhostModule(nn.Module):
    def __init__(self, in_ch, out_ch, kernel_size=3, stride=1, ratio=2):
        primary_out = out_ch // ratio       # 一半通道
        cheap_out = out_ch - primary_out    # 另一半

        self.primary = nn.Sequential(
            nn.Conv2d(in_ch, primary_out, kernel_size, stride, ...),
            nn.BatchNorm2d(primary_out),
            nn.ReLU6(True),
        )
        self.cheap = nn.Sequential(
            nn.Conv2d(primary_out, cheap_out, kernel_size, 1,
                      groups=primary_out, ...),  # 深度可分离
            nn.BatchNorm2d(cheap_out),
        )

    def forward(self, x):
        p = self.primary(x)
        c = self.cheap(p)
        return torch.cat([p, c], dim=1)
\end{lstlisting}

注意廉价卷积后\textbf{不加 ReLU}------这是 GhostNet
论文的设计选择，保留幻影特征图 的线性特性以保持信息多样性。

\subsubsection{SE 注意力模块}\label{se-ux6ce8ux610fux529bux6a21ux5757}

GhostNet 在部分 Bottleneck 中嵌入 SE (Squeeze-and-Excitation)
注意力模块。 SE 模块通过全局平均池化 → 压缩 → 扩展 → hard-sigmoid
门控，自适应地调整 各通道的重要性权重。

为保证 ONNX opset 11 兼容性，本实现使用手动 hard-sigmoid
(\passthrough{\lstinline!relu6 / 6!}) 而非
\passthrough{\lstinline!torch.nn.Hardsigmoid()!}：

\begin{lstlisting}[language=Python]
def forward(self, x):
    s = F.adaptive_avg_pool2d(x, 1)
    s = F.relu6(self.conv1(s)) / 6.0  # hard-sigmoid
    s = self.conv2(s)
    return x * s
\end{lstlisting}

\subsection{2.5.
对比学习训练}\label{ux5bf9ux6bd4ux5b66ux4e60ux8badux7ec3}

掌纹识别是开集验证问题------系统需要判断两张掌纹是否来自同一个人，而非将掌纹
分到某个预定义的类别。因此，本案例使用\textbf{对比学习 (contrastive
learning)} 而非分类交叉熵来训练模型。

对比学习直接优化特征空间中的距离关系：\textbf{同一人的掌纹特征距离近，不同人的
掌纹特征距离远}。训练完成后，新用户注册时只需将其掌纹的特征向量加入
FAISS 索引，无需任何模型更新。

\subsubsection{对比损失函数}\label{ux5bf9ux6bd4ux635fux5931ux51fdux6570}

\begin{lstlisting}[language=Python]
class ContrastiveLoss(nn.Module):
    """L = y * d² + (1-y) * max(0, margin - d)²"""
    def forward(self, emb1, emb2, label):
        dist = F.pairwise_distance(emb1, emb2)
        loss_pos = label * dist.pow(2)           # 正样本：最小化距离
        loss_neg = (1 - label) * \
                   F.relu(self.margin - dist).pow(2)  # 负样本：距离至少 margin
        return (loss_pos + loss_neg).mean()
\end{lstlisting}

\begin{itemize}
\tightlist
\item
  \textbf{正样本对}（同一人）：损失为欧氏距离的平方，驱动特征向量靠近
\item
  \textbf{负样本对}（不同人）：当距离小于 margin
  时产生损失，驱动特征向量远离
\item
  margin 默认为 1.0：意味着负样本对的距离应至少为 1.0
\end{itemize}

\subsubsection{FAISS 索引设计}\label{faiss-ux7d22ux5f15ux8bbeux8ba1}

使用 \passthrough{\lstinline!faiss.IndexFlatIP!}（内积索引）存储 L2
归一化后的 1280 维特征向量。 由于向量已归一化，内积等价于余弦相似度：

\begin{lstlisting}
cosine_similarity(a, b) = a · b  (= faiss inner product when ||a||=||b||=1)
\end{lstlisting}

每个注册用户存储 3-5 个样本的特征向量（对应不同角度/位置的掌纹），验证时
检索 Top-K 个最相似向量，对用户 ID
进行多数投票，取该用户的平均相似度作为 匹配分数。

\subsubsection{多样本注册策略}\label{ux591aux6837ux672cux6ce8ux518cux7b56ux7565}

为什么每个用户需要 3-5 个样本？

{ % do not increment counter
\begin{longtable}[]{@{}lll@{}}
\toprule\noalign{}
样本数 & 优点 & 缺点 \\
\midrule\noalign{}
\endhead
\bottomrule\noalign{}
\endlastfoot
1 & 简单快速 & 对姿态/光照敏感，易拒真 \\
\textbf{3-5} & \textbf{覆盖不同姿态，提高鲁棒性} & 注册稍慢 \\
\textgreater10 & 极高鲁棒性 & 注册耗时长，存储开销大 \\
\end{longtable}
}

验证时，Top-5 个最相似向量中出现最多的用户 ID 即为最佳匹配。例如，若
Top-5 中有 4 个属于用户 A、1 个属于用户 B，则认定匹配用户 A，取这 4
个向量的 平均相似度作为最终分数。

\subsubsection{用户删除}\label{ux7528ux6237ux5220ux9664}

FAISS \passthrough{\lstinline!IndexFlatIP!}
不支持直接删除单条记录。删除用户时，系统通过
\passthrough{\lstinline!reconstruct()!}
方法从索引中取出保留的向量，重建一个新的 FAISS 索引。
对于边缘场景（\textless1000 个用户），这一 O(N) 操作耗时
\textless100ms，完全可以接受。

完整索引管理实现在 \href{samples/case4/palm_index.py}{palm\_index.py} 的
\passthrough{\lstinline!PalmIndex!} 类中。
